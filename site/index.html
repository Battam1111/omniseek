OmniSeek

Give your AI agent the parts of the internet web search doesn't reach.

OmniSeek is an add-on for AI assistants and agents like Claude Code, Cursor, and Codex that lets them search where web search stops.

Get started GitHub
A real run: the agent searches Zhihu and Bilibili and gets linked posts and videos back, about one second each.
  • Web search finds pages about a podcast. Your agent finds the quote, and the minute it was said.
  • Web search finds English pages. Your agent also reads the Chinese threads, and answers in English.
  • Web search finds a list of papers. Your agent finds the map: what is foundational, what is new.
Quoting podcasts needs one optional add-on.

Works with Claude Code, Cursor, Codex, and other AI apps that support MCP, the standard way AI apps add tools.

Zhihu
Questions and answers, with links, without leaving your agent.
Bilibili
Videos and their most-liked comments, no account needed.
Podcasts and videos
Quote what was said and the minute it was said, turned into text on your computer.
New since last time
Watch a topic and see only what's new since last time.
Research papers
Which papers a field is built on, and which recent ones build on them.
Across languages
Ask in English, search Chinese sources, get links to the original posts.

Get started

uv tool install omniseek
claude mcp add omniseek -- omniseek
Python 3.11 or newer; uv installs it if you don't have it.
Claude Code 
claude mcp add omniseek -- omniseek
Cursor
Add to Cursor (opens Cursor), or add this to ~/.cursor/mcp.json:
{"mcpServers": {"omniseek": {"command": "omniseek"}}}
Codex 
codex mcp add omniseek -- omniseek
Other setups
  • Runs on your computer. No OmniSeek cloud, no sign-up, no usage data sent.
  • Sites that need a login stay off until you turn them on, and then use the login already in your browser. OmniSeek never sees your password.
  • Everything it builds up over time is a file on your computer.
