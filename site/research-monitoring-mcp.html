OmniSeek

Research monitoring MCP server: have your AI agent watch a topic and report only what's new

Set a standing query once; OmniSeek reruns it hourly, daily, or weekly across papers, forums, and podcasts, and your agent sees only the results that weren't there last time.

Try it

ASK YOUR AGENT
Watch arXiv for new papers on speculative decoding and tell me what's new each day.
WHAT YOUR AGENT CALLS
omniseek_sensor(action="create", query="speculative decoding",
                sources=["arxiv"], schedule="daily")
omniseek_sensor(action="run", sensor_id="sensor_167bd6000124")
WHAT CAME BACK
  • arxivSecure Speculative Decoding for Large Language Models
  • arxivSpeculative Speculative Decoding
  • arxivSpeculative Decoding and the Curse of Multilinguality

The first three of 15 results from a real first run on 2026-10-10. The first run records the baseline; every later run returns only results that were not in it, and lists any that disappeared if you ask it to.

One sensor can mix sources, for example sources=["arxiv", "reddit", "apple_podcasts"]. Scheduled reruns happen when OmniSeek runs as a long-lived HTTP service (see Install options); over the plain two-command setup, your agent reruns a sensor whenever it calls action="run".

Install

TWO COMMANDS
uv tool install omniseek
claude mcp add omniseek -- omniseek
Python 3.11+; uv fetches it if you don't have it. Cursor, pipx, pip, HTTP, and Docker setups: Install options.
