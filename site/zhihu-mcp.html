OmniSeek

Zhihu MCP server: search Zhihu questions and answers from Claude Code and other MCP clients

Your agent can search Zhihu through public search-engine results with no account, or read full answers through your own Zhihu login if you turn it on (off by default).

知乎 MCP：在 Claude Code 等客户端里让 AI Agent 搜知乎

不登录时，你的 Agent 搜的是公开搜索引擎里的知乎结果；你打开后，它用你自己的知乎登录态读完整回答（默认关）。

Try it

ASK YOUR AGENT
知乎上，博士第一年有哪些建议？给出链接。
WHAT YOUR AGENT CALLS
omniseek_search(query="读博 第一年 建议", sources=["zhihu_search"])
WHAT CAME BACK
  • zhihu_search博士生第一年怎么度过?
  • zhihu_search如果有可能，你会给博士第一年的自己什么建议？
  • zhihu_search有哪些给在读博士的建议？

The first three results from a real run on 2026-10-10, no account. Without a login each result carries the search-engine snippet; your agent can open the page for more.

Zhihu goes through public search-engine results that share one rate-limited backend, so your agent searches it when it names zhihu_search. To read full answers, turn on the zhihu source with your own login, on your own machine: see Logged-in sites.

Install

TWO COMMANDS
uv tool install omniseek
claude mcp add omniseek -- omniseek
Python 3.11+; uv fetches it if you don't have it. Cursor, pipx, pip, HTTP, and Docker setups: Install options.
