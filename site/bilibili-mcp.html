OmniSeek

Bilibili MCP server: let your AI agent search Bilibili videos and comments

Your agent can search Bilibili videos, with view counts and length, and read a video's top comments, with no account and no API key.

B 站 MCP：在 Claude Code 等客户端里让 AI Agent 搜 B 站视频和评论

不用登录，也不用 API key：你的 Agent 能搜 B 站视频（带播放量和时长），也能读一个视频下点赞最多的评论。

Try it

ASK YOUR AGENT
Find Bilibili videos that explain how Python's asyncio works. Give links.
WHAT YOUR AGENT CALLS
omniseek_search(query="Python asyncio 原理", sources=["bilibili"])
WHAT CAME BACK
  • bilibili【python】asyncio的理解与入门，搞不明白协程？看这个视频就够了。 157,565 views, 15:12
  • bilibili【Py】asyncio：为异步编程而生 | Python 特性 | 并发编程 | 协程 78,425 views, 15:26
  • bilibiliPython 异步编程 | async + await + future | 用法 + 原理 + 案例 | 高频面试考点 45,345 views, 92:59

The first three results from a real run on 2026-10-11, no account. Your agent writes the Chinese query itself and answers you in English.

Pass a video link or its BV id as the query and the same source returns that video's top comments, each with its like count. Videos that matter can also be transcribed with timestamps if you install the optional asr extra: see Podcast transcription.

Install

TWO COMMANDS
uv tool install omniseek
claude mcp add omniseek -- omniseek
Python 3.11+; uv fetches it if you don't have it. Cursor, pipx, pip, HTTP, and Docker setups: Install options.
